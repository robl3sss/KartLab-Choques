# Kart Lab · Choques

Simulador educativo 3D de choques unidimensionales y conservación del momento lineal para Física Básica, Centro Universitario de Occidente — CUNOC, Universidad de San Carlos de Guatemala.

Cuatro pilotos, dos pistas, tres tipos de choque, capturas, exportación CSV y música de fondo. Masas asignadas para el modelo, no oficiales.

Abre `index.html` mediante un servidor HTTP local para usar el simulador. No necesita compilación.

Los modelos, imágenes, clips y canciones fueron proporcionados por el usuario. Los personajes y recursos de Mario Kart pertenecen a sus respectivos titulares; este proyecto tiene fines educativos.
